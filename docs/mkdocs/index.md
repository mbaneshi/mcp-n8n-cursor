# MCP N8N Cursor Project

Welcome to the MCP N8N Cursor Project documentation. This project is a scalable AI agent platform designed for small businesses, providing automation and optimization across various business operations.

## Overview

The MCP N8N Cursor Project combines several powerful technologies to create an end-to-end automation solution:

- **Frontend**: Next.js with HuggingFace's Open Chat UI
- **Backend**: FastAPI with Supabase Authentication
- **Workflow Automation**: N8N
- **Database & Auth**: Supabase
- **Observability**: Langfuse
- **AI Components**: 
  - Model Context Protocol (MCP)
  - Google's Agential Development Kit

## Quick Start

1. Clone the repository
2. Set up environment variables
3. Run Docker Compose
4. Access the services
